# EasyMovers: Personal Storage in Dubai Landing Page

Target keyword: **personal storage in dubai**
Anchor text: **See More** (links to https://easymovers.ae/personal-storage-in-dubai/)

## Files

| File | Purpose |
|------|---------|
| `index.html` | Main luxury landing page with animated design and an SEO article (1000+ words) |
| `robots.txt` | Allows all crawlers and points to the sitemap |
| `sitemap.xml` | Sitemap listing the homepage |
| `README.md` | Setup and SEO notes |

## Setup

1. Upload all four files to the root folder of your domain (`https://easymovers.ae/`).
2. Create an `images/` folder beside `index.html` and upload these images with the exact names used in the page:
   - `images/personal-storage-dubai-facility.jpg`
   - `images/luxury-storage-unit-interior.jpg`
3. Until the images are uploaded, the layout still works. The image areas show a dark gold gradient.
4. If your domain is different from `easymovers.ae`, replace the domain in `index.html` (canonical and Open Graph tags), `robots.txt` and `sitemap.xml`.
5. Submit `https://easymovers.ae/sitemap.xml` in Google Search Console and Bing Webmaster Tools.

## SEO Notes

- One `<h1>` containing the target keyword, followed by `<h2>` and `<h3>` headings in logical order.
- Keyword used naturally in the title, meta description, headings, introduction and FAQ.
- Image `alt` text describes each image and includes relevant terms.
- The only outbound link is the "See More" anchor in the second paragraph of the first section.
- Mobile responsive, with lazy-loaded images and `prefers-reduced-motion` support for accessibility.

## Design

- Theme: luxury and premium, using black, charcoal and gold (`#d4af37`) with cream text.
- Animations: shimmering headline, rotating hero glow, fade-up reveals on scroll and hover effects on cards.
- Fonts: Georgia (serif) for an elegant editorial feel, with no external font dependencies.
